# Demo Script

This script provides a structured walkthrough for demonstrating SecureFlow AI to judges, stakeholders, or users.

## 1. Introduction (1 minute)
- **Goal**: Hook the audience and explain the value proposition.
- **Action**: Open the main Dashboard page.
- **Talking Points**: 
  - "Welcome to SecureFlow AI. We built this to solve a critical problem: enterprises need deep security analysis on media assets (images, documents, videos) without sending sensitive data to unpredictable, rate-limited LLMs."
  - "Our solution uses a deterministic rule engine paired with Cloudinary's intelligent extraction to provide instantaneous, reliable security audits."

## 2. The Global Search & Navigation (30 seconds)
- **Goal**: Demonstrate ease of use.
- **Action**: Press `Ctrl+K` to open the command palette. Type "Analysis".
- **Talking Points**: 
  - "The entire platform is instantly navigable. Let's start a new analysis."

## 3. Upload & The Workspace (2 minutes)
- **Goal**: Show media handling and processing capabilities.
- **Action**: Navigate to the Workspace. Upload an image containing a credit card or password.
- **Talking Points**: 
  - "Here is our Transform Studio. Before analysis, users can manipulate media directly via Cloudinary."
  - *Demonstrate rotating or applying a blur.*
  - "Once ready, we run the Security Analysis."

## 4. The Security Analysis Engine (2 minutes)
- **Goal**: Highlight the core innovation (Zero-LLM dependency).
- **Action**: Click "Run Analysis". Wait for the redirect to the Evidence Report.
- **Talking Points**: 
  - "Notice how fast that was. We didn't wait 15 seconds for an OpenAI response."
  - "Instead, Cloudinary extracted the OCR text and tags on the fly. Our local SecureFlow Engine instantly evaluated those against security rules."
  - *Scroll through the report.*
  - "You can see it correctly identified the resource type, extracted the text, and flagged the high-risk credentials."

## 5. Aggregated Findings & Reporting (1 minute)
- **Goal**: Show organizational value.
- **Action**: Navigate to the "Findings" page, then "Reports".
- **Talking Points**: 
  - "All these individual analyses aggregate into a comprehensive security posture."
  - "Security teams can monitor trends and investigate critical vulnerabilities across the entire organization."

## 6. Conclusion (30 seconds)
- **Goal**: Summarize and close.
- **Action**: Return to Dashboard.
- **Talking Points**: 
  - "SecureFlow AI provides robust, deterministic media security. It's fast, privacy-focused, and completely independent of third-party LLM rate limits."
